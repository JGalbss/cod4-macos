# jgalbs cod4 0.2.10 release candidate

This build makes joining the jgalbs community-map rotation reliable for a new
player. The DMG includes pinned copies of Rust, Terminal, and Scrapyard and the
app installs them into `~/Library/Application Support/cod4/usermaps` on launch.
Players no longer need to wait for these maps to download while connecting.

The application still excludes all Call of Duty 4 retail game data. Players
must select their legally owned Call of Duty 4 data directory on first launch.
The included third-party community maps retain their author credits and source
links in `COMMUNITY-MAPS-NOTICE.txt`.
